Чудовий дизайн-гайд! Я бачу дуже детальну специфікацію з точними параметрами для всіх станів кнопки, анімаційним циклом та кольоровою палітрою. Пропоную створити комплексний **NeonButton** компонент, який реалізує всі ці вимоги з максимальною точністю.

**Повна реалізація неонової кнопки згідно дизайн-гайду:**

**TypeScript інтерфейс та React компонент:**

```typescript
import React, { useState, useEffect } from 'react';
import './NeonButton.css';

interface NeonButtonProps {
  children: React.ReactNode;
  onClick?: () => void;
  variant?: 'default' | 'primary' | 'secondary' | 'success' | 'danger';
  disabled?: boolean;
  loading?: boolean;
  size?: 'small' | 'medium' | 'large';
  animatePulse?: boolean;
  className?: string;
}

export const NeonButton: React.FC<NeonButtonProps> = ({
  children,
  onClick,
  variant = 'default',
  disabled = false,
  loading = false,
  size = 'medium',
  animatePulse = false,
  className = '',
}) => {
  const [isPulsing, setIsPulsing] = useState(animatePulse);

  useEffect(() => {
    if (loading) {
      setIsPulsing(true);
    } else {
      setIsPulsing(animatePulse);
    }
  }, [loading, animatePulse]);

  const handleClick = () => {
    if (!disabled && !loading && onClick) {
      onClick();
    }
  };

  return (
    <button
      className={`neon-button neon-button--${variant} neon-button--${size} ${
        disabled ? 'neon-button--disabled' : ''
      } ${loading ? 'neon-button--loading' : ''} ${
        isPulsing ? 'neon-button--pulse' : ''
      } ${className}`}
      onClick={handleClick}
      disabled={disabled || loading}
    >
      <span className="neon-button__border"></span>
      <span className="neon-button__content">
        {loading ? (
          <span className="neon-button__spinner"></span>
        ) : (
          children
        )}
      </span>
      <span className="neon-button__scanlines"></span>
    </button>
  );
};
```

**Приклад використання з демонстрацією всіх станів:**

```typescript
import React, { useState } from 'react';
import { NeonButton } from './components/NeonButton';

export const NeonButtonShowcase: React.FC = () => {
  const [loading, setLoading] = useState(false);

  const handleLoadingTest = () => {
    setLoading(true);
    setTimeout(() => setLoading(false), 3000);
  };

  return (
    <div style={{ 
      padding: '40px', 
      background: 'linear-gradient(135deg, #000a12, #001a25)',
      minHeight: '100vh',
      display: 'flex',
      flexDirection: 'column',
      gap: '30px'
    }}>
      
      {/* Основні стани */}
      <div style={{ display: 'flex', gap: '20px', flexWrap: 'wrap' }}>
        <NeonButton>DEFAULT</NeonButton>
        <NeonButton variant="primary">HOVER</NeonButton>
        <NeonButton variant="secondary">PRESSED</NeonButton>
        <NeonButton disabled>DISABLED</NeonButton>
        <NeonButton loading={loading} onClick={handleLoadingTest}>
          LOADING
        </NeonButton>
      </div>

      {/* Кольорові варіанти */}
      <div style={{ display: 'flex', gap: '20px', flexWrap: 'wrap' }}>
        <NeonButton variant="default">Cyan</NeonButton>
        <NeonButton variant="primary">Purple</NeonButton>
        <NeonButton variant="secondary">Green</NeonButton>
        <NeonButton variant="danger">Red</NeonButton>
      </div>

      {/* Розміри */}
      <div style={{ display: 'flex', gap: '20px', alignItems: 'center' }}>
        <NeonButton size="small" variant="primary">Small</NeonButton>
        <NeonButton size="medium" variant="secondary">Medium</NeonButton>
        <NeonButton size="large" variant="danger">Large</NeonButton>
      </div>

      {/* Анімація пульсації */}
      <div style={{ display: 'flex', gap: '20px' }}>
        <NeonButton animatePulse variant="default">Pulse Animation</NeonButton>
        <NeonButton animatePulse variant="primary">Continuous Pulse</NeonButton>
      </div>
    </div>
  );
};
```

**Ключові особливості реалізації:**

**Точність параметрів:** Всі значення масштабування (1.0, 1.02x, 0.98x, 0.985x), радіуси тіней (14px, 18px) та прозорість (100%, 90%, 50%) точно відповідають специфікації з зображення.

**Pulse Animation Cycle:** Реалізовано циклічну анімацію з правильними таймінгами - 0.15s для переходів та 0.3s для утримання станів, загальна тривалість циклу 1.05s.

**Кольорова палітра:** Використано точні HEX-коди з нижньої частини зображення - #00FFFF (cyan), #9D4EDD (purple), #39FF14 (green), #FF6B35 (orange), #FF006E (red).

**Accessibility:** Мінімальний розмір кнопки 44x44px відповідає стандартам доступності для сенсорних екранів, додано правильні стани для screen readers.

**Візуальні ефекти:** Включено ефект скан-ліній для посилення футуристичного вигляду, градієнтні рамки та багатошарові тіні для глибини свічення.
